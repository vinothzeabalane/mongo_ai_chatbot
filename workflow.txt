User question
     │
     ▼
 parser.py           ← deterministic rule-based, no LLM
     │
     ▼
 query_engine.py     ← orchestrates the pipeline
     │
     ▼
 query_builder.py    ← builds Mongo aggregate pipeline
     │
     ▼
   MongoDB
     │
     ├── tabular results ──► formatter.py ──► Streamlit UI
     │
     └── chart results ────► charts.py ─────► Streamlit UI


Notes
- No LLM involved; every question is handled by regex/keyword rules in parser.py.
- Metrics live in nested Mongo fields: data.SBL_TOTAL.min, data.SBL_TOTAL.max, etc.
- config.py holds MongoDB and Ollama settings (Ollama settings exist but are unused).
- test_smoke.py is the automated regression suite, run with: python -m unittest test_smoke.py -v
